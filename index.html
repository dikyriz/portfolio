About Me

Hello! I'm Dicky, a Computer Science graduate from Dr. Soetomo University in Surabaya. I work as a freelance developer, splitting my time between two things I love: IoT engineering and front-end development.

On the IoT side, I design systems around ESP32, ESP8266, and Arduino — sensor monitoring, RFID access control, voice-controlled automation — wired up to mobile apps via MQTT and Telegram.

On the web side, I build responsive interfaces with React, Next.js, and Tailwind CSS, and ship them to production on Vercel and Netlify.

Here are a few technologies I've been working with recently:

  • ESP32 / ESP8266
  • Arduino (C/C++)
  • React / Next.js
  • JavaScript / TypeScript
  • Tailwind CSS
  • MQTT / REST API
